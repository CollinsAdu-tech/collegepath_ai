# API Reference

Base URL (local dev): `http://localhost:8000`. Interactive docs (Swagger
UI) are auto-generated by FastAPI at `/docs`, and the raw OpenAPI schema
at `/openapi.json`.

## `GET /health`

Liveness check.

**Response `200`**
```json
{ "status": "ok" }
```

## `GET /categories`

Returns every category declared in the knowledge base, read from the
already-loaded, in-memory `KnowledgeBaseService` (no disk access per
request).

**Response `200`**
```json
{ "categories": ["Admissions Fundamentals", "After Admission", "..."] }
```
(16 categories in the current knowledge base.)

## `POST /chat`

The main endpoint. Validates input, retrieves, applies the confidence
threshold, and returns either a sourced answer or a fallback.

**Request**
```json
{ "message": "What is Early Action?" }
```

**Response `200` — confident answer**
```json
{
  "answer": "Early Action is generally a nonbinding early application option. Specific restrictions and deadlines vary by college.",
  "matched_question": "What is Early Action?",
  "category": "Decision Types",
  "similarity_score": 0.8367,
  "source": {
    "name": "College Board — College Application FAQ",
    "url": "https://bigfuture.collegeboard.org/plan-for-college/apply-to-college/college-application-faq"
  },
  "verification_date": "2026-09-20",
  "related_questions": ["What is Restrictive Early Action?", "..."],
  "fallback": false,
  "requires_current_verification": false
}
```

**Response `200` — fallback** (`similarity_score` below the configured
threshold; see `docs/retrieval.md`)
```json
{
  "answer": "I'm not confident that I found the right answer for that question. Try asking it another way, or choose one of the topics below.",
  "matched_question": null,
  "category": null,
  "similarity_score": null,
  "source": null,
  "verification_date": null,
  "related_questions": ["...near-miss questions, framed as topics to explore..."],
  "fallback": true,
  "requires_current_verification": false
}
```

**Response `200` — dynamic/current-information record** (a Dynamic
College Information match — see Section 23/24). The answer text never
invents a specific date/rate/policy, and `source.url` is `null` rather
than a fake link when the true source is "the college's own official
page" and not one fixed URL:
```json
{
  "answer": "Verify the deadline on the college's official admissions page for the exact entry year and applicant type.",
  "category": "Dynamic College Information",
  "source": { "name": "The specific college's official admissions website", "url": null },
  "requires_current_verification": true,
  "fallback": false,
  "...": "..."
}
```

**Response `400`** — the message failed a business-rule check
(empty/whitespace-only, or over `MAX_QUERY_LENGTH` characters):
```json
{ "detail": "Query cannot be empty." }
```

**Response `422`** — the request body failed shape validation (missing
`message` field, or `message` isn't a string). Generated automatically
by FastAPI/Pydantic before any application code runs.

**Response `500`** — an unexpected server error. The response never
includes a stack trace or internal detail:
```json
{ "detail": "An internal server error occurred." }
```

## Notes on `similarity_score`

This is the retrieval engine's cosine-similarity score for the matched
record, in `[0, 1]`. It is **not** a probability of correctness and is
unrelated to the knowledge base's own `confidence` field (Section 16) —
treat it as an internal ranking signal, not something to display to end
users as a percentage.

## CORS

Configured explicitly (`CORS_ORIGINS` in `.env`), not left wide open.
The default covers both `http://localhost:5173` and
`http://127.0.0.1:5173` for local development — browsers treat these as
different origins even though they're the same machine, so both are
needed (this was a real bug found during Phase 10 integration testing).
